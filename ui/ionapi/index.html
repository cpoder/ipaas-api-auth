Infor requires the four secrets for a service account (client id / secret of the authorized app + saak / sask). The .ionapi file merely bundles them.

The four secrets (client id / secret, saak / sask) are stored in the Integration Server encrypted store. No token to enter: the package obtains it, caches it and renews it.
